# BSU V8.4 — демо-принадлежность факультетам и кафедрам

Это **исключительно Frontend-демо**. Не меняет Backend V7.4, FastAPI, PostgreSQL или публичные страницы.

## Добавлено

- Кабинет факультета: выбор одной из существующих записей `faculty-data.ts`.
- Кабинет кафедры: выбор одной из существующих записей `department-data.ts`.
- Материалы хранят `owner`, `ownerSlug`, `ownerName`. Показаны только материалы выбранного подразделения.
- ЦЦР видит все отправленные материалы с указанием факультета/кафедры; можно одобрить или вернуть с замечанием.
- Сохранены этапы `draft → submitted → approved` или `submitted → changes_requested → submitted`.
- Исправлены повреждённые русские подписи из старого компонента.
- Хранилище демо использует **новый ключ** `bsu-editorial-workflow-demo-v2`; данные из v1 не удаляются, но не показываются в v2 из-за отсутствия идентификаторов подразделений.

## Ограничения безопасности

Селектор не является защитой доступа: любой посетитель **локальной демоверсии** может выбрать другой факультет, кафедру и даже открыть очередь ЦЦР. Все записи остаются в localStorage, не передаются на сервер и не публикуются. Не вводить конфиденциальные данные. Реальная работа потребует серверных ролей/авторизации/аудита и API записи; эти возможности **не входят** в публичный read-only MVP.

## Установка

Заменить только `src/components/admin/EditorialDemo.tsx`. Существующие `/admin/faculty`, `/admin/department`, `/admin/review` должны продолжить передавать `role="faculty"`, `role="department"`, `role="review"` соответственно. Если эти страницы не перенесены локально, сначала восстановить их из уже подготовленного V7.8; в ZIP здесь они не заменяются.

Проверки: `npx tsc --noEmit`, `npm run lint`, `npm run build` (при запущенном локальном API, если включён backend mode). Запуск `npm run dev`, тест: выбрать факультет → создать новость → отправить ЦЦР → открыть `/admin/review` → вернуть на доработку → исправить в том же факультете.

Оставаться в интеграционной ветке, не сливать в main до проверки. Контракт Backend V7.4 не менять.
