# BSU V8.13 · фотографии новостей (только локальный тест)

- Максимум 8 изображений на материал; JPEG/PNG/WEBP, не более 5 МБ и 25 Мп на фото.
- Фото хранятся в PostgreSQL (`editorial_media.data`), не в эфемерной файловой системе Docker.
- Первое фото автоматически становится обложкой; её можно сменить или удалить в черновике.
- После отправки в ЦЦР фото блокируются до возврата на доработку.
- Закрытые изображения доступны автору и ЦЦР только по Bearer-сессии; публичные ссылки отвечают 404 до одобрения.
- В публичный News.image_url обложка переносится только во время решения ЦЦР `approve=true`.
- Публичный GET `/api/v1/news/{slug}/gallery` возвращает изображения только опубликованной новости; старый API контракт `/news` не расширяется.
- Локальный Next.js проксирует изображения через `/media/news/{slug}/{id}.{ext}` и отображает галерею.
- Раздел медиа появляется в карточке **после первого сохранения черновика**. Фото добавлять перед отправкой ЦЦР.
- Загрузка доступна только в dev Next.js, BFF не раскрывает bearer-токен браузеру.
- Тестовая база `bsu_auth_v88_test`, API `8001`; не мигрировать основную `bsu`.
- При тестировании публичной страницы временно переключить `BSU_API_BASE_URL` с `8000` на `8001`, затем восстановить.
- Большое число фотографий в БД ухудшит производительность: для production лучше S3-совместимое объектное хранилище и превью/ресайз, плюс отдельные лимиты и аудит.

## Установка

Из корня проекта после распаковки ZIP с заменой файлов:

```powershell
python scripts/apply-v8-13.py
python -m compileall -q backend/app backend/alembic/versions
npx tsc --noEmit
npm run lint
docker compose build api
$testUrl = 'postgresql://bsu:bsu_local_password@db:5432/bsu_auth_v88_test'
docker compose run --rm --no-deps -e "DATABASE_URL=$testUrl" api alembic upgrade head
```

Проверить `0004_media`, затем пересоздать **только** тестовый API `bsu-auth-v88-api` с `DATABASE_URL=$testUrl`. Основной API `8000` не перезапускать.

При первом запуске Next.js после распаковки: `npm run dev -- -p 3100`. Войти редактором, сохранить черновик, прикрепить фото, отправить, войти ЦЦР и одобрить.

## Ограничения

- Отдельный аудит пользовательских изменений и антивирусная проверка файлов пока не реализованы.
- При текущей архитектуре редактирование опубликованных новостей недоступно.
- Не публиковать в интернет без отдельного security review.
