# BSU Search v1
Local public catalogue search: faculties, departments, staff, programs, news, documents, navigation. It indexes existing public metadata and available translations; it does not crawl external files, private AVN or missing staff records. Index builds once per locale when used. Header panel loaded on demand. Ctrl/Cmd+K, Escape, category chips, six quick results and full /search?q= page. Exact titles and words ranked ahead of substring and one-edit typo matches (5+ characters). No external API or new dependency. Short acronyms match whole words; not semantic AI. Future backend contract GET /api/v1/search?q=&locale=&category=&page=&limit=; return published public records only.
